บทความ / ภาษามือไทย

สะกดนิ้วภาษามือไทย ก–ฮ เข้าใจหลักแล้วจำได้เอง.

ตารางสะกดนิ้วไทยดูครั้งแรกเหมือนต้องท่องสี่สิบกว่าท่า แต่จริงๆ แล้วมันสร้างจากท่าพื้นฐานไม่กี่ท่า บวกกับท่าตัวเลขเพื่อแยกตัวที่เสียงเหมือนกัน พอเห็นหลักนี้ ที่เหลือแทบไม่ต้องท่อง

โดย ทีมใดๆภาษา18 ตุลาคม 2569อ่าน 5 นาที

01สะกดนิ้วไม่ใช่ภาษามือทั้งหมด

เรื่องแรกที่ควรรู้คือ คนหูหนวกไม่ได้สะกดนิ้วทุกคำ ภาษามือไทยเป็นภาษาเต็มรูปแบบ มีคำศัพท์และไวยากรณ์ของตัวเอง คำว่า “กิน” “บ้าน” หรือ “ขอบคุณ” มีท่าเฉพาะที่ทำได้ในจังหวะเดียว

การสะกดนิ้วเป็นเครื่องมือเสริมในภาษามือ ใช้กับคำที่ไม่มีท่าเฉพาะ เช่น ชื่อคน ชื่อสถานที่ ยี่ห้อ หรือศัพท์เทคนิค ถ้าคุณเพิ่งเริ่มเรียน การสะกดชื่อตัวเองให้คล่องเป็นจุดเริ่มต้นที่ดี เพราะเป็นสิ่งแรกที่ต้องใช้เมื่อแนะนำตัว

02หลักเดียวที่ใช้ทั้งตาราง

พยัญชนะไทยทำด้วยมือข้างเดียว แต่ละตัวยืมท่ามาจากตัวอักษรภาษาอังกฤษในภาษามืออเมริกัน (ASL) ที่เสียงใกล้กัน ภาษามือไทยปัจจุบันได้รับอิทธิพลจาก ASL มาก ก จึงใช้ท่า K ส ใช้ท่า S และ พ ใช้ท่า P

ภาษาไทยมีพยัญชนะเสียงซ้ำกันหลายตัว เช่น ต ถ ฐ ฒ ฑ ฏ ที่ล้วนออกเสียงคล้ายกัน วิธีแยกคือทำท่าตัวหลักก่อน แล้วตามด้วยท่าตัวเลข 1–5 ตัวที่ใช้บ่อยที่สุดได้ท่าเดี่ยว ตัวที่ใช้น้อยลงได้เลขต่อท้ายมากขึ้น

ตัวอักษรตถฐฒฑฏ
ท่าTT → 1T → 2T → 3T → 4T → 5

พยัญชนะที่ภาษาอังกฤษเขียนด้วยสองตัวก็สะกดสองท่าตามนั้น ท คือ T แล้ว H ฉ คือ C แล้ว H ส่วน ง คือ N แล้ว G

04สระ: ชี้บนฝ่ามืออีกข้าง

สระส่วนใหญ่ไม่ได้ทำเป็นท่ามือ แต่ใช้นิ้วชี้ของมือที่สะกดไปแตะตำแหน่งต่างๆ บนมืออีกข้างที่แบฝ่ามือหันออก ลองนึกภาพว่ามือข้างนั้นเป็นแผนที่ นิ้วแต่ละนิ้วมีสองจุดคือปลายนิ้วกับโคนนิ้ว

ตำแหน่งที่แตะปลายนิ้วโคนนิ้ว
นิ้วชี้ะา
นิ้วกลางุู
นิ้วนางเแ
นิ้วก้อย์ (การันต์)ฤ
นิ้วโป้งำ็ (ไม้ไต่คู้)

นอกจากนั้น แตะกลางฝ่ามือคือไม้หันอากาศ ( ั ) และแตะสันมือด้านล่างคือ ฯ

มีสระบางตัวที่ใช้ท่ามือของตัวเองแทนการแตะ

โอO

สระประสมอย่าง เอีย หรือ เอือ สะกดตามรูปที่เขียนทีละส่วน เช่น เอีย คือ เ ตามด้วย ี และ ย เครื่องมือของเราก็สะกดแบบนี้เช่นกัน

05วรรณยุกต์: แตะจากด้านบน

วรรณยุกต์ใช้ตำแหน่งปลายนิ้วเหมือนสระ แต่แตะจากด้านบนของปลายนิ้วลงมา เรียงจากนิ้วชี้ถึงนิ้วก้อยตามลำดับ

ไม้เอก ( ่ )ไม้โท ( ้ )ไม้ตรี ( ๊ )ไม้จัตวา ( ๋ )
นิ้วชี้นิ้วกลางนิ้วนางนิ้วก้อย

06ลองสะกด “สวัสดี”

ส (S) → ว (W) → แตะกลางฝ่ามือ ( ั ) → ส (S) → ด (D) → ี (S)

สังเกตว่า ส กับสระอี ใช้ท่า S เหมือนกัน คนดูแยกได้จากตำแหน่งในคำ ซึ่งเป็นเรื่องปกติของการสะกดนิ้ว คนที่ใช้เป็นประจำจะอ่านเป็นคำ ไม่ได้อ่านทีละตัว

พิมพ์ชื่อคุณแล้วดูท่าทีละตัวเครื่องมือวาดท่ามือให้ครบทั้งพยัญชนะ สระ และวรรณยุกต์ พิมพ์ภาษาอังกฤษก็ได้ จะแสดงเป็น ASL

07ฝึกยังไงให้ติดมือ

  • จำเป็นกลุ่ม เรียนท่าหลัก K T S P ให้คล่องก่อน ตัวที่ต่อเลขท้ายจะตามมาเอง
  • เริ่มจากชื่อตัวเอง ฝึกจนสะกดได้ลื่นโดยไม่หยุดคิด แล้วต่อด้วยชื่อคนในบ้าน
  • ฝึกอ่าน ไม่ใช่แค่ฝึกทำ การอ่านการสะกดนิ้วของคนอื่นยากกว่าทำเองมาก ดูวิดีโอจากครีเอเตอร์หูหนวกบ่อยๆ ช่วยได้มาก
  • เรียนกับผู้สอนจริง ถ้าอยากสื่อสารกับคนหูหนวกได้จริง ควรเรียนภาษามือไทยทั้งภาษา ไม่ใช่แค่การสะกดนิ้ว มีหลักสูตรภาษามือไทยเปิดสอนอยู่หลายแห่ง เช่น ที่สมาคมคนหูหนวกแห่งประเทศไทยและในมหาวิทยาลัย

รายละเอียดของท่าบางตัวอาจต่างกันเล็กน้อยตามแหล่งที่เรียน ตารางนี้เทียบกับตารางสะกดนิ้วมือไทยที่ใช้ในโรงเรียนสอนคนหูหนวก และฟอนต์ Nattanan TSL Fingerspelling ที่เผยแพร่ผ่านโรงเรียนเศรษฐเสถียร ในพระราชูปถัมภ์

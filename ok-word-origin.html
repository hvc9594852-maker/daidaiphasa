ภาษาต่างประเทศ

มุกสะกดผิดที่กลายเป็นคำของทั้งโลก

คำที่คนไทยพิมพ์ตอบในไลน์วันละหลายสิบครั้ง เริ่มต้นจากบรรณาธิการหนังสือพิมพ์คนหนึ่งที่จงใจสะกดคำว่า all correct ผิดเพื่อเล่นมุก แล้วมุกนั้นก็ไม่ยอมตายมาเกือบสองร้อยปี

เรื่อง ทีมใดๆภาษา28 ตุลาคม 2569อ่าน 7 นาที

หัวหน้าส่งงานมาในไลน์ตอนห้าทุ่ม เราพิมพ์ตอบสั้นๆ ว่า โอเคค่ะ หรือถ้าเหนื่อยมากก็แค่ ok สองตัวอักษรนี้ทำงานได้ทุกอย่าง ตั้งแต่รับทราบ ตกลง ไม่เป็นไร ไปจนถึงก็งั้นๆ แหละ มันอยู่บนปุ่มในหน้าจอคอมพิวเตอร์ อยู่ในบทสนทนาของคนญี่ปุ่น ฝรั่งเศส และคนไทย จนแทบลืมไปว่ามันเป็นคำภาษาอังกฤษ

แต่ถ้าถามว่า OK ย่อมาจากอะไร หลายคนจะตอบว่า all correct ซึ่งถูกแค่ครึ่งเดียว เพราะตัวอักษร O กับ K ไม่ได้อยู่ในคำว่า all correct เลยสักตัว คำตอบที่ครบกว่านั้นต้องย้อนไปที่โต๊ะบรรณาธิการในเมืองบอสตันเมื่อปี 1839 ยุคที่นักหนังสือพิมพ์อเมริกันกำลังติดเกมหนึ่งงอมแงม

แฟชั่นคำย่อของคนบอสตัน

อัลเลน วอล์กเกอร์ รีด นักวิชาการจากมหาวิทยาลัยโคลัมเบีย ผู้ใช้เวลาไล่อ่านหนังสือพิมพ์เก่าจนไขปริศนาคำนี้ได้ในทศวรรษ 1960 พบว่าตั้งแต่ราวฤดูร้อนปี 1838 หนังสือพิมพ์ในบอสตันพากันเล่นมุกด้วยการย่อวลีให้เหลือแต่ตัวอักษรตัวแรก เช่น R.T.B.S. มาจาก remains to be seen แปลว่ารอดูกันต่อไป หรือ S.P. มาจาก small potatoes ที่หมายถึงเรื่องเล็กไม่สลักสำคัญ

เล่นไปเล่นมา มุกก็ซับซ้อนขึ้นอีกชั้น คือย่อจากคำที่ตั้งใจสะกดผิด อย่าง K.G. ที่มาจาก know go แทน no go หรือ O.W. ที่มาจาก oll wright แทน all right ซึ่งปรากฏในหนังสือพิมพ์ Boston Morning Post เมื่อต้นเดือนกุมภาพันธ์ 1839 คนอ่านสมัยนั้นต้องถอดรหัสสองรอบ รอบแรกคือนึกให้ออกว่าย่อมาจากอะไร รอบที่สองคือเข้าใจว่าคำนั้นสะกดผิดโดยเจตนา คล้ายกับที่คนไทยรุ่นนี้เข้าใจทันทีว่า ชิมิ หรือ จุงเบย ไม่ได้พิมพ์ผิด

วันที่ 23 มีนาคม 1839

ชาร์ลส์ กอร์ดอน กรีน บรรณาธิการ Boston Morning Post เป็นหนึ่งในคนที่เล่นมุกนี้บ่อยที่สุด ในฉบับวันที่ 23 มีนาคม 1839 เขาเขียนบทความล้อหนังสือพิมพ์คู่แข่งจากเมืองพรอวิเดนซ์ เกี่ยวกับสมาคมต่อต้านการตีระฆังที่ตั้งชื่อย่อขำๆ ว่า A.B.R.S. และในบทความนั้นเองที่ตัวอักษร o.k. ปรากฏขึ้น ตามด้วยคำขยายว่า all correct

เบื้องหลังสองตัวอักษรนั้นคือ oll korrect คำว่า all correct ที่ถูกสะกดผิดให้ฟังเหมือนคนไม่รู้หนังสือ เป็นมุกเดียวกับ oll wright ที่ใช้มาก่อนหน้าไม่กี่สัปดาห์ แอลลัน เม็ตคาล์ฟ นักภาษาศาสตร์ผู้เขียนหนังสือว่าด้วยคำนี้ทั้งเล่ม ถึงกับเรียกมันว่ามุกที่ไม่ค่อยตลกเท่าไร

คำที่คนทั้งโลกใช้บอกว่าทุกอย่างเรียบร้อยดี เริ่มต้นจากการสะกดผิดโดยตั้งใจ

มุกคำย่อส่วนใหญ่ในยุคนั้นตายไปพร้อมกับกระแส ไม่มีใครพูด R.T.B.S. หรือ K.G. อีกแล้ว OK เองก็น่าจะมีชะตากรรมเดียวกัน ถ้าไม่ได้รับแรงส่งจากการเมือง

ชายชราจากคินเดอร์ฮุก

ปี 1840 ประธานาธิบดีมาร์ติน แวน บิวเรน ลงสมัครเลือกตั้งอีกสมัย เขามีชื่อเล่นว่า Old Kinderhook ตามชื่อเมืองคินเดอร์ฮุกในรัฐนิวยอร์กที่เป็นบ้านเกิด และบังเอิญว่าชื่อเล่นนี้ย่อได้ว่า O.K. พอดี ผู้สนับสนุนในนิวยอร์กจึงตั้งชมรม Democratic O.K. Club ขึ้นมา คำว่า OK เลยมีความหมายสองชั้นในคราวเดียว คือทั้งชื่อผู้สมัคร และนัยว่าทุกอย่างเรียบร้อยดี

ฝ่ายตรงข้ามก็ไม่ปล่อยให้คำนี้ลอยนวล พวกเขาปล่อยเรื่องเล่าว่าแอนดรูว์ แจ็กสัน ประธานาธิบดีคนก่อนที่เป็นพันธมิตรของแวน บิวเรน สะกดคำไม่เป็น จึงเขียน O.K. ลงบนเอกสารที่อนุมัติ เพราะคิดว่า all correct สะกดแบบนั้น เม็ตคาล์ฟชี้ว่าจริงๆ แล้วแจ็กสันสะกดคำได้ดี แต่มุกล้อเลียนก็ทำหน้าที่ของมันไปแล้ว คือช่วยกระจายคำนี้ไปทั่วประเทศ ผลการเลือกตั้งออกมาว่าแวน บิวเรนแพ้ แต่คำว่า OK อยู่รอดต่อมา

สายโทรเลขช่วยชีวิตไว้อีกครั้ง

หลังการเลือกตั้ง คำนี้ค่อยๆ เปลี่ยนจากมุกมาเป็นเครื่องหมายบนเอกสาร ภายในราวสองทศวรรษ คนอเมริกันเขียน OK ลงบนกระดาษเพื่อบอกว่าตรวจแล้วผ่าน จังหวะเดียวกันนั้นโทรเลขก็เริ่มแพร่หลาย พนักงานโทรเลขต้องการคำสั้นที่สุดสำหรับบอกว่าได้รับข้อความครบแล้ว และพอถึงทศวรรษ 1870 สองตัวอักษรนี้ก็กลายเป็นคำมาตรฐานในวงการโทรเลข

ถึงอย่างนั้น โลกวรรณกรรมก็ยังมองว่ามันเป็นคำบ้านๆ นักเขียนอย่างมาร์ก ทเวน หลีกเลี่ยงไม่ใช้ ส่วนหลุยซา เมย์ อัลคอตต์ ผู้เขียน Little Women ถึงกับเปลี่ยนคำว่า OK ในหนังสือของเธอเป็นคำอื่นเมื่อพิมพ์ฉบับหลัง เป็นอาการเดียวกับที่ภาษาวัยรุ่นทุกยุคต้องเจอ ก่อนที่วันหนึ่งจะกลายเป็นภาษาที่ทุกคนใช้โดยไม่รู้ตัว

ศตวรรษต่อมา OK ไปไกลถึงอวกาศ เมื่ออลัน เชพเพิร์ด ขึ้นบินในเดือนพฤษภาคม 1961 สื่อพากันรายงานว่าเขาพูดว่า A-OK ทั้งที่บันทึกการสนทนาอย่างเป็นทางการมีแค่คำว่า okay ธรรมดา และในวันที่ยานอะพอลโล 11 ลงจอดบนดวงจันทร์ในปี 1969 นักบินอวกาศก็ใช้คำว่า okay อยู่หลายครั้ง

ทฤษฎีที่ผิดแต่ยังถูกเล่าต่อ

เพราะคนรุ่นหลังลืมไปแล้วว่าคำนี้มาจากไหน ช่องว่างนั้นจึงถูกเติมด้วยเรื่องเล่าสารพัด บ้างว่ามาจากคำว่า okeh ในภาษาช็อกทอว์ของชนพื้นเมืองอเมริกัน ซึ่งเคยมีผู้เสนอไว้ตั้งแต่ปี 1885 และเชื่อกันอยู่นาน บ้างว่ามาจากท่าเรือ Aux Cayes ในเฮติที่ขึ้นชื่อเรื่องเหล้ารัม จากวลีกรีก ola kala ที่แปลว่าทุกอย่างดี จากสำนวนสกอต och aye หรือจากรหัส open key ของพนักงานโทรเลข

รีดตรวจสอบทฤษฎีเหล่านี้ทีละข้อ และตีพิมพ์ผลการค้นคว้าในวารสาร American Speech ช่วงปี 1963 ถึง 1964 ข้อสรุปของเขาคือไม่มีหลักฐานว่า OK ถูกใช้ในความหมายนี้ก่อนบทความของกรีนในปี 1839 ทุกทฤษฎีที่อ้างว่าเก่ากว่านั้นล้วนตามหาเอกสารยืนยันไม่ได้ ความน่าเชื่อถือของงานชิ้นนี้ทำให้นักนิรุกติศาสตร์รุ่นหลังยอมรับคำอธิบายเรื่อง oll korrect กันเป็นส่วนใหญ่ จนเม็ตคาล์ฟเสนอให้วันที่ 23 มีนาคมเป็นวัน OK และมีการฉลองครั้งแรกในปี 2011

โอเคในภาษาไทย

เมื่อเดินทางมาถึงภาษาไทย OK กลายเป็นคำทับศัพท์ที่เขียนว่า โอเค และไม่ได้ทำหน้าที่แค่บอกว่าถูกต้อง แต่ยังใช้บอกระดับความพอใจได้ด้วย เช่น อาหารร้านนี้ก็โอเคนะ ซึ่งแปลว่าพอใช้ได้ ไม่ถึงกับอร่อย หรือ เธอโอเคไหม ที่หมายถึงสบายดีไหม ทั้งหมดนี้ยังเป็นเครือญาติกับความหมายเดิมที่ว่าไม่มีอะไรผิดปกติ

ครั้งหน้าที่พิมพ์ ok ตอบใครสักคน ลองนึกถึงชาร์ลส์ กอร์ดอน กรีน ที่นั่งเขียนบทความล้อคู่แข่งในบอสตันเมื่อเกือบสองร้อยปีก่อน เขาคงไม่คาดคิดว่ามุกสะกดผิดที่ตัวเองเขียนเล่นในวันนั้นจะเดินทางข้ามโลกไปไกลกว่าชื่อของเขาเองหลายเท่า และยังทำงานได้ดีอยู่ทุกวันในแชทของคนที่ไม่เคยได้ยินชื่อเมืองบอสตันด้วยซ้ำ

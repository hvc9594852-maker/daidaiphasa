# โฟลเดอร์ร่างบทความ (drafts)

อัปโหลดร่างบทความไว้ในโฟลเดอร์นี้ (บน GitHub: Add file → Upload files) งานประจำวันจะหยิบร่างที่เก่าที่สุดไปตรวจข้อเท็จจริง แล้วขึ้นเว็บวันละหนึ่งเรื่อง ร่างที่ใช้แล้วจะถูกย้ายออกจากโฟลเดอร์นี้ ถ้าไม่มีร่างเหลืออยู่ Claude จะเขียนบทความเอง

- ชื่อไฟล์ได้ตามสะดวก ลงท้ายด้วย `.py` (ตามรูปแบบด้านล่าง) หรือ `.md` / `.txt` (ข้อความธรรมดาที่มีหัวเรื่อง เนื้อหา และลิงก์แหล่งที่มา)
- ไฟล์ในโฟลเดอร์นี้ไม่ถูก build ขึ้นเว็บโดยตรง
- ถ้าร่างไหนซ้ำกับเรื่องที่มีอยู่แล้ว หรือข้อเท็จจริงหลักยืนยันไม่ได้ ร่างนั้นจะถูกย้ายไป `drafts/rejected/` พร้อมเหตุผล

## Prompt สำหรับ AI ตัวอื่น (คัดลอกทั้งก้อนไปวาง แล้วแก้บรรทัด "หัวข้อ")

```
ช่วยเขียนบทความภาษาไทย 1 เรื่องให้เว็บ ใดๆภาษา.com เว็บเครื่องมือและเรื่องเล่าเกี่ยวกับภาษาสำหรับคนไทยทั่วไป (ไม่ใช่นักวิชาการ)

หัวข้อ: <ใส่หัวข้อ เช่น "ที่มาของคำว่า เจ๊ง" หรือเขียนว่า "เลือกเอง">

== ภาพรวมของบทความที่ต้องการ ==
บทความเล่าเรื่องแบบนิตยสาร (อย่าง The Cloud หรือศิลปวัฒนธรรมฉบับอ่านง่าย) ไม่ใช่รายงาน ไม่ใช่บทความ SEO ไม่ใช่ลิสต์ "10 ข้อ" ผู้อ่านควรรู้สึกเหมือนมีเพื่อนที่รู้เรื่องภาษาเล่าให้ฟัง ได้ความรู้ที่เอาไปเล่าต่อได้ และมีข้อมูลจริงรองรับทุกข้อ

== ความยาวและโครงสร้าง ==
- เนื้อหายาวราว 4,500–6,000 ตัวอักษรไทย (ประมาณ 1,000–1,400 คำ)
- ย่อหน้าราว 16–22 ย่อหน้า แต่ละย่อหน้า 2–5 ประโยค ไม่มีย่อหน้าบรรทัดเดียวติดกันหลายย่อหน้า
- หัวข้อย่อย (h2) 4–6 หัวข้อ หัวข้อละ 2–4 ย่อหน้า
- โครงเรื่องที่ใช้ได้ดี:
  1) ย่อหน้าเปิด: ฉากในชีวิตจริงที่คนไทยนึกภาพออก (ร้านค้า ห้องเรียน แชตไลน์ ซีรีส์ ป้ายรถเมล์) หรือคำถามที่ชวนสงสัย แล้วโยงเข้าเรื่องภายใน 2 ย่อหน้า
  2) กลางเรื่อง: เล่าตามลำดับเวลา หรือตามเส้นทางของคำ/ตัวอักษร ใส่ชื่อคน ปี สถานที่ หลักฐานจริง
  3) ช่วงท้าย: เทียบกับภาษาอื่น หรือพาเรื่องกลับมาที่ชีวิตวันนี้ หรือหลักการใช้ที่ถูกต้อง
  4) ย่อหน้าปิด: ย้อนกลับไปที่ฉากเปิด หรือทิ้งภาพ/ข้อคิดสั้น ๆ ไม่สรุปซ้ำทุกประเด็น
- มีประโยคเด่น (pull quote) 1 ประโยคกลางเรื่อง เป็นประโยคของเราเอง ไม่ใช่คำพูดของคนจริง
- ถ้ามีข้อมูลเปรียบเทียบหลายรายการ (เช่น คำในหลายภาษา) ใส่ตาราง 1 ตารางได้ ไม่บังคับ

== ภาษาและน้ำเสียง ==
- ภาษาเขียนที่เป็นกันเอง สุภาพ ไม่ใช้ภาษาพูดแรง ๆ ไม่ใช้คำแสลงเกินจำเป็น ไม่ใช้อีโมจิ
- เว้นวรรคแบ่งวลีแบบภาษาไทยปกติ ไม่ใช้จุลภาค (,) ไม่ใช้เครื่องหมายคำพูด (" ") ถ้าต้องยกคำให้เขียนตรง ๆ เช่น คำว่า ฝรั่ง
- ใช้ไม้ยมกแบบเว้นวรรคหน้าหลัง เช่น ช้า ๆ
- คำต่างประเทศ: เขียนคำอ่านภาษาไทยก่อน แล้ววงเล็บตัวสะกดเดิมเมื่อจำเป็น เช่น ชาวแฟรงก์ (Franks)
- ตัวเลขใช้เลขอารบิก ปีไทยใช้ พ.ศ. ปีสากลใช้ ค.ศ. หรือ "ศตวรรษที่ 16" ตามแหล่งที่มา
- ห้ามสำนวนแบบ AI เช่น ในยุคปัจจุบัน / ในโลกที่เปลี่ยนแปลงอย่างรวดเร็ว / ไม่ว่าจะเป็น...หรือ... / นอกจากนี้ยัง / อีกทั้ง / ถือเป็น...ที่สำคัญ / กล่าวโดยสรุป / ท้ายที่สุดแล้ว / มาดูกันเลย / เรียกได้ว่า / อย่างไรก็ตาม (ใช้ได้น้อยที่สุด)
- ห้ามขึ้นต้นด้วย "ลองนึกภาพ" (ใช้บ่อยแล้ว) ห้ามตั้งคำถามแล้วตอบเองซ้ำ ๆ ทุกย่อหน้า
- ไม่ใส่ตัวเลขหน้าหัวข้อ ไม่ใช้ bullet หรือรายการในเนื้อหา เล่าเป็นย่อหน้าทั้งหมด
- หัวข้อย่อย (h2) สั้น 3–8 คำ เป็นวลีที่ชวนอ่าน ไม่ใช่ "ความหมาย" "ประวัติ" "สรุป" แบบแห้ง ๆ เช่น "ศิลาจารึกที่ยังไม่มีไม้ยมก" "เมื่อโรงพิมพ์บังคับให้เลือกทาง"

== ข้อเท็จจริงและแหล่งที่มา ==
- ทุกข้อเท็จจริง ตัวเลข ชื่อคน วันที่ ต้องมาจากแหล่งที่เปิดอ่านได้จริงบนเว็บ ห้ามแต่งเอง ห้ามเดา ห้ามสร้างลิงก์ที่ไม่มีอยู่จริง ถ้าไม่แน่ใจให้ตัดทิ้ง เรื่องที่นักวิชาการยังเถียงกันให้เขียนว่าเป็นข้อสันนิษฐานหรือมีหลายความเห็น
- แหล่งที่ดี: ราชบัณฑิตยสถาน/สำนักงานราชบัณฑิตยสภา, พจนานุกรมออนไลน์ทางการ, วารสารวิชาการใน ThaiJO, ศิลปวัฒนธรรม (silpa-mag.com), เว็บมหาวิทยาลัยหรือหน่วยงานรัฐ, Wikipedia (ใช้ได้แต่ไม่ควรเป็นแหล่งเดียว), Britannica, Etymonline, สำนักข่าวหลัก
- sources 4–8 แหล่ง (ขั้นต่ำ 2) ทุกลิงก์ต้องเปิดได้โดยไม่ต้องล็อกอิน
- ห้ามคัดลอกข้อความจากแหล่งอื่น เขียนใหม่ด้วยภาษาของตัวเองทั้งหมด

== สิ่งที่ห้าม ==
- เนื้อเพลง บทกวี หรือข้อความยาวที่มีลิขสิทธิ์ (บอกชื่อเพลง/หนังได้ แต่ห้ามยกเนื้อร้อง)
- เขียนถึงบุคคลจริงในทางเสียหาย เรื่องการเมืองที่เป็นข้อถกเถียง
- โฆษณาหรือแนะนำสินค้า/คอร์สแบบเชียร์
```

# โฟลเดอร์ร่างบทความ (drafts)

อัปโหลดร่างบทความไว้ในโฟลเดอร์นี้ (บน GitHub: Add file → Upload files) งานประจำวันจะหยิบร่างที่เก่าที่สุดไปตรวจข้อเท็จจริง แล้วขึ้นเว็บวันละหนึ่งเรื่อง ร่างที่ใช้แล้วจะถูกย้ายออกจากโฟลเดอร์นี้ ถ้าไม่มีร่างเหลืออยู่ Claude จะเขียนบทความเอง

- ชื่อไฟล์ได้ตามสะดวก ลงท้ายด้วย `.py` (ตามรูปแบบด้านล่าง) หรือ `.md` / `.txt` (ข้อความธรรมดาที่มีหัวเรื่อง เนื้อหา และลิงก์แหล่งที่มา)
- ไฟล์ในโฟลเดอร์นี้ไม่ถูก build ขึ้นเว็บโดยตรง
- ถ้าร่างไหนซ้ำกับเรื่องที่มีอยู่แล้ว หรือข้อเท็จจริงหลักยืนยันไม่ได้ ร่างนั้นจะถูกย้ายไป `drafts/rejected/` พร้อมเหตุผล

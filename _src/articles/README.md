# ตัวสร้างหน้าบทความ (ใดๆภาษา.com)

แก้เนื้อหาที่ไฟล์ในโฟลเดอร์นี้ แล้วรัน `python3 build.py` (จากโฟลเดอร์ไหนก็ได้) จะเขียนไฟล์ HTML, article.css และเพิ่ม URL ใหม่ลง sitemap.xml ที่รากของเว็บโดยตรง

- `posts/` บทความรายวัน หนึ่งไฟล์ต่อหนึ่งเรื่อง ชื่อไฟล์ `YYYY-MM-DD-slug.py` (ดูตัวอย่าง `posts/2026-10-18-how-the-world-types-laughter.py`)
- `guides.py` บทความที่เรียนภาษา 7 เรื่อง และค่า `CHECKED`
- `build.py` บทความเรื่องเล่า 6 เรื่อง เทมเพลตหน้า และหน้ารวม /articles (เรื่องใหม่ล่าสุดขึ้นเป็นเรื่องเด่นอัตโนมัติ)
- `covers.py` ภาพปก บทความใน posts/ ใช้ปกแบบตัวอักษรอัตโนมัติจากค่า `cover`
- `article.css` สไตล์ (ถ้าแก้ CSS ให้เปลี่ยนเลข `?v=` ใน build.py ด้วย)

## วิธีเพิ่มบทความใหม่
สร้างไฟล์ใน `posts/` ที่กำหนดตัวแปร `ARTICLE = dict(...)` มีคีย์:
`slug` (อังกฤษ ตัวเล็ก คั่นด้วย -, ห้ามซ้ำ), `date_iso` (2026-10-19), `date_th` (19 ตุลาคม 2569), `cat` (หมวด สั้นๆ), `title` (ชื่อสำหรับ Google), `h1` (หัวเรื่องสั้นแบบนิตยสาร), `dek` (คำโปรย 1–2 ประโยค), `desc` (meta description), `card` (บรรทัดบนการ์ด), `cover` = `{'big': 'คำใหญ่บนปก (สั้น)', 'small': 'บรรทัดเล็ก', 'bg': '#สีอ่อน'}`, `body` (HTML), `sources` (รายการ (ชื่อ, URL)) และอาจมี `tool`/`tool_name` (ลิงก์เครื่องมือในเว็บที่เกี่ยวข้อง เช่น /keyboard /romanize /translate /slang /pasa-lu /braille /morse /sign-language)

ใน `body` ใช้: `<p class="first">` ย่อหน้าแรก, `<h2>` หัวข้อย่อย, `<p class="end">` ย่อหน้าสุดท้าย, ตารางใช้ `<div class="scroll"><table class="spec">…</table></div>`, คำพูดเด่นใช้ `<blockquote class="pq"><p>…</p></blockquote>`

## กติกา
- เรื่องห้ามซ้ำกับเรื่องที่มีอยู่ (ดูชื่อไฟล์ใน posts/ และหัวเรื่องใน build.py, guides.py)
- ทุกข้อเท็จจริงต้องมีแหล่งที่มาที่เปิดอ่านได้จริง ห้ามเดาราคา ตัวเลข หรือวันที่
- เขียนภาษาไทยแบบนิตยสาร อ่านเป็นธรรมชาติ ไม่ใช้สำนวนแบบ AI ไม่ใส่ตัวเลขกำกับหัวข้อ
- ห้ามคัดลอกเนื้อหาจากแหล่งอื่น เขียนใหม่ด้วยภาษาของเราเอง

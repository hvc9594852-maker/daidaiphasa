# ตัวสร้างหน้าบทความ (ใดๆภาษา.com)

แก้เนื้อหาที่ไฟล์ในโฟลเดอร์นี้ แล้วรัน `python3 build.py` (ต้องรันจากโฟลเดอร์นี้) จะเขียนไฟล์ HTML และ article.css ลงรากของเว็บโดยตรง

- `guides.py` บทความที่เรียนภาษา 7 เรื่อง (ราคา ที่อยู่ แหล่งที่มา) และค่า `CHECKED` = วันที่ตรวจข้อมูลล่าสุด
- `build.py` บทความเรื่องเล่า 6 เรื่อง เทมเพลตหน้า และหน้ารวม /articles · ค่า `DATE_ISO`/`DATE_TH` คือวันที่ของบทความ
- `covers.py` ภาพปก SVG · `article.css` สไตล์ (ถ้าแก้ CSS ให้เปลี่ยนเลข `?v=` ใน build.py ด้วย เพื่อกันเบราว์เซอร์จำไฟล์เก่า)

กติกา: ห้ามใส่ราคาที่เดาเอง ถ้าหาไม่ได้ให้เขียน "สอบถาม" ราคาจากรีวิวต้องบอกว่าเป็นรีวิวและใส่ปี ทุกตัวเลขต้องมีลิงก์ที่มา

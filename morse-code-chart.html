รหัสมอร์ส

จุดกับขีดที่ยังไม่ยอมเงียบ

รหัสที่เกิดมาพร้อมโทรเลขเมื่อเกือบสองร้อยปีก่อน ยังดังอยู่ในหูฟังของนักวิทยุสมัครเล่น และในห้องนักบินจนถึงทุกวันนี้

เรื่อง ทีมใดๆภาษา18 ตุลาคม 2569อ่าน 5 นาที

รหัสมอร์สมีของอยู่แค่สองอย่าง สัญญาณสั้นกับสัญญาณยาว ด้วยสองอย่างนี้ มันส่งได้ทุกตัวอักษร ส่งผ่านสายไฟก็ได้ ผ่านคลื่นวิทยุก็ได้ กะพริบไฟฉายหรือเคาะผนังห้องก็ยังได้

ความเรียบง่ายแบบนี้ทำให้มันอยู่รอดมาได้นานเกินกว่าเทคโนโลยีที่ให้กำเนิดมัน โทรเลขหายไปจากชีวิตคนส่วนใหญ่นานแล้ว แต่จุดกับขีดยังไม่เงียบ

ข้อความแรกบนสายโทรเลข

รหัสมอร์สเกิดขึ้นพร้อมโทรเลขไฟฟ้าในทศวรรษ 1830 แซมูเอล มอร์ส พัฒนามันร่วมกับอัลเฟรด เวล และวันที่ 24 พฤษภาคม 1844 ข้อความโทรเลขทางการฉบับแรกก็วิ่งจากวอชิงตันไปถึงบัลติมอร์ ข้อความนั้นคือ What hath God wrought

รหัสที่เราใช้กันทุกวันนี้ไม่ใช่รหัสชุดเดิมของอเมริกา แต่เป็นรหัสมอร์สสากลที่ปรับปรุงในยุโรป และกลายเป็นมาตรฐานระหว่างประเทศหลังการประชุมโทรเลขที่ปารีสในปี 1865 ก่อนจะถูกยกไปใช้กับวิทยุอีกหลายสิบปีต่อมา

ตัวที่ใช้บ่อยได้รหัสสั้น

ถ้าดูตารางผ่านๆ อาจคิดว่ารหัสถูกแจกแบบสุ่ม แต่มันมีตรรกะ E กับ T ซึ่งเป็นตัวที่พบบ่อยที่สุดในภาษาอังกฤษ ได้รหัสสั้นที่สุด คือจุดเดียวกับขีดเดียว ตัวที่นานๆ เจอทีอย่าง Q หรือ Z ได้รหัสยาวสี่สัญญาณ ยิ่งใช้บ่อย ยิ่งส่งเร็ว

หลายตัวยังเป็นภาพกลับด้านของกันและกันด้วย A ( ·– ) กับ N ( –· ) D ( –·· ) กับ U ( ··– ) K ( –·– ) กับ R ( ·–· ) ใครอยากจำ เริ่มจากกลุ่ม E T I A N M ก่อน แล้วค่อยจับคู่ตรงข้ามที่เหลือ

ตัวเลขเป็นส่วนที่จำง่ายที่สุด ทุกตัวยาวห้าสัญญาณ เลข 1 คือจุดหนึ่งตามด้วยขีดสี่ เลขถัดไปเพิ่มจุดทีละตัว จนเลข 5 เป็นจุดล้วน แล้วเลข 6 ถึง 0 กลับด้าน เริ่มด้วยขีดแล้วตามด้วยจุด

จังหวะสำคัญพอๆ กับรหัส

รหัสมอร์สไม่ได้มีแค่จุดกับขีด ช่องว่างก็เป็นส่วนหนึ่งของภาษา ถ้าเว้นจังหวะผิด จุดสามตัวของ S อาจกลายเป็น E สามตัว รหัสมอร์สสากลจึงกำหนดความยาวไว้เป็นหน่วย จุดยาวหนึ่งหน่วย ขีดยาวสามหน่วย ช่องว่างในตัวอักษรเดียวกันหนึ่งหน่วย ระหว่างตัวอักษรสามหน่วย และระหว่างคำเจ็ดหน่วย

เวลาเขียนเป็นตัวหนังสือ คนนิยมเว้นวรรคหนึ่งครั้งระหว่างตัวอักษร และใช้ / คั่นระหว่างคำ แต่คนที่ใช้มอร์สคล่องไม่ได้นับจุด เขาฟังเป็นเสียง C ฟังเหมือน “ดา-ดิ-ดา-ดิ” ถ้าอยากจำให้ติด ฟังซ้ำๆ จะได้ผลกว่าจ้องตาราง

SOS ไม่ได้ย่อมาจากอะไรเลย มันถูกเลือกเพราะจำง่ายและฟังผิดยาก

เรื่องจริงของ SOS

หลายคนเคยได้ยินว่า SOS ย่อมาจาก Save Our Souls หรือ Save Our Ship เรื่องนี้ฟังโรแมนติก แต่ไม่จริง การประชุมวิทยุโทรเลขระหว่างประเทศที่เบอร์ลินในปี 1906 เลือกรูปแบบสั้นสาม ยาวสาม สั้นสาม เป็นสัญญาณขอความช่วยเหลือ เพราะจังหวะของมันชัดจนฟังผิดได้ยาก และเริ่มใช้จริงในปี 1908 ส่วนคำย่อที่เล่าต่อกันมาถูกแต่งขึ้นทีหลัง

แล้วภาษาไทยล่ะ

ภาษาไทยมีรหัสมอร์สของตัวเอง ใช้ในวงการวิทยุและงานสื่อสารของบางหน่วยงาน โดยกำหนดรหัสให้พยัญชนะ สระ และวรรณยุกต์ไทยแยกจากตารางสากล ตอนนี้เครื่องมือของเรายังแปลงได้เฉพาะตัวอักษรอังกฤษกับตัวเลข ถ้าจะใช้มอร์สไทยในงานจริง ควรใช้ตารางจากหน่วยงานหรือชมรมวิทยุที่สังกัด

ส่วนคำถามว่ายังมีใครใช้อยู่ไหม คำตอบคือมากกว่าที่คิด นักวิทยุสมัครเล่นทั่วโลกยังส่งมอร์สกันทุกวัน เพราะมันทะลุสัญญาณที่อ่อนมากๆ ได้ สถานีช่วยเดินอากาศอย่าง VOR และ NDB ยังส่งชื่อย่อของสถานีเป็นรหัสมอร์สให้นักบินฟังยืนยัน และแป้นพิมพ์ Gboard บนมือถือก็มีโหมดพิมพ์ด้วยมอร์ส ให้คนที่ขยับร่างกายได้จำกัดพิมพ์ได้ด้วยปุ่มเพียงสองปุ่ม

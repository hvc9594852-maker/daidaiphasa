บทความ / รหัสมอร์ส

รหัสมอร์ส จุดกับขีดที่ยังไม่ตายมา 180 ปี.

รหัสมอร์สใช้แค่สองสัญลักษณ์ คือสัญญาณสั้นกับสัญญาณยาว แต่ส่งได้ทุกตัวอักษร ส่งได้ทั้งทางเสียง ไฟกะพริบ หรือเคาะผนัง ถึงทุกวันนี้นักวิทยุสมัครเล่นและเครื่องช่วยนำทางเครื่องบินบางชนิดก็ยังใช้อยู่

โดย ทีมใดๆภาษา18 ตุลาคม 2569อ่าน 4 นาที

01เริ่มจากโทรเลข

รหัสมอร์สเกิดขึ้นพร้อมกับโทรเลขไฟฟ้าในช่วงทศวรรษ 1830 โดยแซมูเอล มอร์ส ทำงานร่วมกับอัลเฟรด เวล วันที่ 24 พฤษภาคม 1844 ข้อความโทรเลขทางการฉบับแรกถูกส่งจากวอชิงตันไปบัลติมอร์ ว่า “What hath God wrought”

รหัสที่ใช้กันทั่วโลกวันนี้คือ รหัสมอร์สสากล ซึ่งปรับปรุงในยุโรปจากรหัสเดิมของอเมริกา และกลายเป็นมาตรฐานระหว่างประเทศตั้งแต่การประชุมโทรเลขระหว่างประเทศที่ปารีสในปี 1865 ก่อนจะถูกนำไปใช้กับวิทยุในอีกหลายสิบปีต่อมา

04จังหวะสำคัญพอๆ กับรหัส

ถ้าเว้นจังหวะผิด จุดสามตัวของ S อาจกลายเป็น E สามตัวได้ รหัสมอร์สสากลกำหนดความยาวเป็นหน่วยแบบนี้

สัญญาณความยาว
จุด ( · )1 หน่วย
ขีด ( – )3 หน่วย
ช่องว่างในตัวอักษรเดียวกัน1 หน่วย
ช่องว่างระหว่างตัวอักษร3 หน่วย
ช่องว่างระหว่างคำ7 หน่วย

เวลาเขียนเป็นตัวหนังสือ คนนิยมเว้นวรรคหนึ่งครั้งระหว่างตัวอักษร และใช้ / คั่นระหว่างคำ เครื่องมือของเราก็เขียนแบบนี้

05SOS ไม่ได้ย่อมาจากอะไร

หลายคนเข้าใจว่า SOS ย่อมาจาก Save Our Souls หรือ Save Our Ship แต่จริงๆ ไม่ได้ย่อมาจากอะไรเลย การประชุมวิทยุโทรเลขระหว่างประเทศที่เบอร์ลินในปี 1906 เลือกรูปแบบนี้เป็นสัญญาณขอความช่วยเหลือเพราะจำง่ายและฟังผิดยาก มีผลใช้จริงตั้งแต่ปี 1908 ส่วนคำย่อที่คนชอบเล่ากันถูกแต่งขึ้นทีหลัง

06จำแบบเข้าใจ ไม่ต้องท่อง

  • ตัวที่ใช้บ่อยรหัสสั้น E กับ T ซึ่งเป็นตัวที่พบบ่อยที่สุดในภาษาอังกฤษ ได้รหัสสั้นที่สุด คือจุดเดียวกับขีดเดียว เริ่มจำจากกลุ่มนี้ก่อน: E T I A N M
  • จับคู่ตรงข้าม หลายตัวเป็นภาพกลับด้านของกันและกัน A ( ·– ) กับ N ( –· ), D ( –·· ) กับ U ( ··– ), K ( –·– ) กับ R ( ·–· )
  • ฟังเป็นเสียง ไม่ใช่นับจุด คนที่ใช้มอร์สคล่องจำเป็นจังหวะ เช่น C ฟังเหมือน “ดา-ดิ-ดา-ดิ” ลองกดปุ่มฟังเสียงในเครื่องมือแล้วฟังซ้ำๆ จะติดหูเร็วกว่าดูตาราง

แปลงข้อความเป็นมอร์ส แล้วฟังเสียงจริงพิมพ์ภาษาอังกฤษหรือตัวเลข หรือใส่จุดกับขีดเพื่อแปลกลับ

07แล้วรหัสมอร์สภาษาไทยล่ะ

ภาษาไทยก็มีรหัสมอร์สของตัวเอง ใช้ในวงการวิทยุและงานสื่อสารบางหน่วยงาน โดยกำหนดรหัสให้พยัญชนะ สระ และวรรณยุกต์ไทยแยกจากตารางสากล ตอนนี้เครื่องมือของเราแปลงได้เฉพาะตัวอักษรภาษาอังกฤษและตัวเลข ถ้าจะใช้มอร์สไทยในงานจริง ควรใช้ตารางจากหน่วยงานหรือชมรมวิทยุที่คุณสังกัด

08ยังมีใครใช้อยู่ไหม

มีมากกว่าที่คิด นักวิทยุสมัครเล่นทั่วโลกยังส่งมอร์สกันทุกวัน เพราะส่งได้ไกลแม้สัญญาณอ่อนมาก สถานีวิทยุช่วยเดินอากาศอย่าง VOR และ NDB ส่งชื่อย่อของสถานีเป็นรหัสมอร์สให้นักบินฟังยืนยัน และแป้นพิมพ์ Gboard บนมือถือก็มีโหมดพิมพ์ด้วยมอร์ส ซึ่งช่วยคนที่ขยับร่างกายได้จำกัดให้พิมพ์ได้ด้วยปุ่มเพียงสองปุ่ม
